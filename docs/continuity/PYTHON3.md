# Python 3 compatibility: bounded regression path

Status: local compatibility candidate; scoped engineering checks passed on
18 October 2026. Scientific review is pending. This branch adds Python 3 syntax/import compatibility to the CLI and its
imported modules, and updates dependency APIs needed for the bundled single-site
regression example. Other modes and converters are not verified by this work.

The modern environment uses Python 3.13, NumPy 2.5.4, SciPy 1.18.1, pandas 3.0.6,
h5py 3.16.0, PyTables 3.11.1 and bitarray 3.12.2. Use the [standalone Docker reference guide](RUN_REFERENCE.md);
the immutable base image and resolved dependency lock identify the environment.
The standalone entry point needs only a POSIX shell and Docker on the host.

Compatibility edits: explicit relative imports, Python 3 print/iterator/exception
syntax, pickle import, maintained inspection and NumPy build-information APIs,
CSV to_numpy, keyword HDF selectors, builtin integer/string dtype aliases in the
tested path, and integer division for genotype file/chunk indexing.

Bundled legacy probe tables have byte-valued pandas metadata that pandas 3 rejects.
A narrow PyTables reader extracts their ID column in bounded row chunks and
decodes its text. It accepts only the declared legacy frame_table string-block
schema and leaves the source HDF5 files unchanged. Modern table metadata retains
the pandas reader. This is input compatibility, not a change to the model.

The HASE regression formulas and singular-matrix policy are unchanged. A_inverse
changes xrange to range, its Timer import becomes explicit-relative, and its
diagnostic print becomes Python 3 syntax. Reference fixture, exact OLS algorithm
and provisional tolerances are unchanged. No blanket allow_pickle change is made
to scientific input loading.

Acceptance is defined in the local pilot plan: help, the small independent
reference and deliberate-error detection through Kit, full ExampleStudy, and a
Kit-recorded comparison against the archived legacy outputs. The example comparison
checks all saved association identities, shapes, finite MAF/SE/t/coefficient values
and input/output hashes using the unchanged provisional thresholds. It loads only
hash-identified dictionaries generated by our own recorded local runs. It is not
an arbitrary pickle loader or independent validation of the large ExampleStudy.

Tolerances and scientific interpretation still require a named scientific reviewer.
No release, upstream push, institution deployment, SPACE adapter or global Kit
acceptance is established by this branch. Selected dated execution results are included in the
[public evidence bundle](evidence/README.md); full original records remain archived
locally. These results are scoped observations, not inferred implementation claims.

See PYTHON3_VERIFICATION.md for the completed checks, measured differences and
remaining limits. This status/verification documentation was added after execution;
the tested runtime files are unchanged.
